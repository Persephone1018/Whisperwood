# Whisperwood — Phase 2 Complete + Phase 3

This build keeps the Phase 2B visual baseline and adds the remaining story engine work.

## Phase 2 completion
- Relationship progression with five stages
- Trust, tension and relationship points
- Consequences from previous interactions
- Meaningful memory retrieval
- Story flags for truth, leaving/staying, touch and threats
- Scene mood and thread state
- Character dossier used as canon
- Local state persistence and v4 migration

## Phase 3
- Story event system with one-off and recurring events
- Plot, atmosphere, trust, intimacy and agency beats
- Autonomous Tristan check-ins based on relationship stage
- Event history and unread moments
- Relationship progression triggered by choices and events
- Manual “Invite a story moment” control
- Recent-event memory
- Persephone agency rule preserved: the engine never writes Persephone’s thoughts, feelings, dialogue, choices or actions

## Notes
This remains a local browser prototype. Autonomous moments can occur while the app is open; a real background notification/server system would be a later backend phase.
