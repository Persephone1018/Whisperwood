# Whisperwood — Phase 7

A private, local-first interactive story-world prototype.

## What changed
- Added a living world pulse with place, time, atmosphere and scene description.
- Added a story cabinet / artifact system with interactive object cards.
- Added richer character-profile presentation and a quick profile view from the story.
- Added scene context for location, time, mood and character presence.
- Strengthened the chat presentation around dialogue + action + atmospheric notes.
- Added more dynamic scene descriptions tied to Tristan's responses.
- Preserved local saves and migration from Whisperwood v6/v5/v4.
- Preserved the agency rule: Persephone remains fully user-controlled.
